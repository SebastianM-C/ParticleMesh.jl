# Subpackages

Present: `ParticleMeshCore` (the engine: particles, grids, transfers including the charge-conserving `deposit_flux!`, sort, loading, mesh operators, KernelAbstractions kernels; no physics) and `ParticleMeshElectromagnetic` (self-consistent electromagnetic PIC, the only physics module, A9; for N = 1 periodic so far: the Yee field layout and solver, the relativistic Boris pusher behind a pusher type, the module's step composed from engine pieces, with the current through the core's `deposit_flux!`, and the problem description kept apart from the numerics, A10; the electrostatic cases, Landau damping and the two-stream instability, run as its edge cases with no transverse momenta or fields, and Weibel as the third 1D case; field boundaries and the filter come with the 2D LWFA module).

Planned, in the order they are expected to appear: `Wakefields` (laser-wakefield acceleration on top of `ParticleMeshElectromagnetic`: moving window, antenna, LWFA diagnostics), `ParticleMeshMTK` (symbolic front-end), `ParticleMeshReactant` (Reactant path and the stress-test suite), `RunManifests` (run provenance, lifted from an earlier project).

Each is a package of its own with its own tests and a member of the root Pkg workspace, so all share the committed root `Manifest.toml`; packages reach each other, and the umbrella reaches them, through `[sources]` with relative paths. There is no electrostatic package (A9): the electromagnetic module runs the electrostatic cases with no transverse fields.

# Subpackages

Planned, in the order they are expected to appear: `ParticleMeshCore` (the engine: particles, grids, transfers, sort, loading, mesh operators, KernelAbstractions kernels; no physics), `ParticleMeshElectromagnetic` (self-consistent electromagnetic PIC: Yee, Boris, field boundaries, filter; the current through the core's charge-conserving `deposit_flux!`; the electrostatic cases, Landau damping and the two-stream instability, run as its edge cases with no transverse fields, A9), `Wakefields` (laser-wakefield acceleration on top of `ParticleMeshElectromagnetic`: moving window, antenna, LWFA diagnostics), `ParticleMeshMTK` (symbolic front-end), `ParticleMeshReactant` (Reactant path and the stress-test suite), `RunManifests` (run provenance, lifted from an earlier project). Each is a package of its own with its own tests and a member of the root Pkg workspace, so all share the committed root `Manifest.toml`; the umbrella reaches them through `[sources]` with relative paths. There is no electrostatic package (A9): until the electromagnetic module reproduces the electrostatic cases, their reference is the WP-010 spike's step, kept as test-support code in `ParticleMeshCore/test/es_reference.jl`.

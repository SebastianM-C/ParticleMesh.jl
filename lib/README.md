# Subpackages

Planned, in the order they are expected to appear: `ParticleMeshCore` (particles, grids, transfers, KernelAbstractions kernels, time-loop harness), `ParticleMeshElectrostatic` (the electrostatic PIC module and the 1D benchmark set), `ParticleMeshElectromagnetic` (self-consistent electromagnetic PIC: Yee, Boris, field boundaries, filter; the current through the core's charge-conserving `deposit_flux!`), `Wakefields` (laser-wakefield acceleration on top of `ParticleMeshElectromagnetic`: moving window, antenna, LWFA diagnostics), `ParticleMeshMTK` (symbolic front-end), `ParticleMeshReactant` (Reactant path and the stress-test suite), `RunManifests` (run provenance, lifted from an earlier project). Each is a package of its own with its own tests and a member of the root Pkg workspace, so all share the committed root `Manifest.toml`; the umbrella reaches them through `[sources]` with relative paths.

# WP-093: feature support over N dimensions

Lift the refusals by dimension in the electromagnetic module that nothing in the physics asks for: the binomial filter and the sort from the last order at N = 3, the filter beside an open axis, the step without current at N = 1, the witness bunch at N = 3 and the 3D shaped antenna with the M4 solver, with one state constructor over N ≥ 2, so that what stays refused is written once and says why. It works when each lifted feature passes at its new N what its 2D form passes (the filter's transfer function and filtered Gauss law, the resort's bits against the full sort, the witness's gain against its closed form, the M4 antenna's launched pulse) in Float32, Float64 and `Dual{Float32,3}`, on the CPU and on CUDA, and every Reference digest of the existing runs keeps its bits.

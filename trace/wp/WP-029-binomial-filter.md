# WP-029: the binomial current filter

The binomial current filter with the pass count from the case file (A2), in both deposition modes, replacing the loader's refusal of filter_passes ≠ 0. It works when its transfer function matches the closed form mode by mode, its effect on Gauss's law is measured and stated, and the 2D Landau and Weibel cases are unchanged with zero passes.

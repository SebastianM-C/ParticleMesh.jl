# WP-039: Landau theory for each code's thermal load

Give the Landau cases a theory value for each code's own thermal load with the relativistic push, as a new case version or observable so the cited case hashes stay, and use it to explain the 1D ensembles' low rates and their opposite late-time noise trends. It works when each load's rate matches an independent quadrature to about 1e-5 and each code's ensemble sits within its errors of its own load's value.

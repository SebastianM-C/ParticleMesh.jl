# A7. Acceptance criteria and budgets per work package

Conservation residuals (Gauss's law to roundoff with Esirkepov, energy drift bound over N steps), agreement thresholds against the benchmark set, a throughput budget (nanoseconds per particle-step on the 4080 SUPER, within a stated factor of Smilei on the same card), memory budget (the `FunctionMap` harness doubles state; on 16 GB that caps 2D with P = 3 at roughly 10⁷ particles), and gradient-check tolerances.

How tolerances are set: measure, then propose; the owner accepts a proposed value by editing this file. Physics correctness is caught by tests against analytic solutions and conservation laws, held close to roundoff (a stated multiple of `eps(T)` scaled by the problem size and step count), not by loose agreement with other codes. Agreement thresholds for the benchmark set rest on the measured spread between Smilei and PIConGPU for equivalent inputs: ParticleMesh must agree with each of them to within that spread, and the spread is measured, never assumed. Finite-difference gradient checks have precision limits of their own: choose the step from a scan (truncation error falls and cancellation error grows as the step shrinks), use common random numbers and the deterministic reference mode on both sides, run the check in Float64 even where the production type is Float32, and state the tolerance against the error the scan shows.

# A5. Canonical benchmark cases with numbers

The 1D set (Landau damping, two-stream growth rate, Weibel) with expected values; two 2D LWFA cases, each fully specified (a₀, w₀, τ, n₀, ramp, box, resolution, particles per cell, steps, diagnostics) and also run in Smilei and PIConGPU (containerized). The first, a deterministic laser and wake with little injection, is `scripts/lwfa/cases/lwfa-2d.toml`: a₀ = 2, w₀ = 28 c/ω₀, τ = 26/ω₀ (1/e half width of the field), n₀ = 0.01 n_c behind 260 c/ω₀ of vacuum and a 60 c/ω₀ sin² ramp, focus at the plateau's start, Δx = λ₀/48, Δy = 4Δx, Δt at 0.95 of the Courant limit, 2 × 2 electrons per cell, immobile ions, no current filter, periodic transverse boundaries, 10 777 steps. The second is an injecting case, proposed after the first is run in all three codes. Experience from earlier cross-code work: matched setups are the under-specified, labor-intensive part; do it once, in a versioned config.

Verification against both PIConGPU and Smilei covers correctness and performance. For the performance comparison to be fair the configs must match shape-function order, current deposition scheme (Esirkepov in all three), filtering, precision (PIConGPU defaults to FP32, Smilei to FP64), particles per cell and output cadence, and run on the same card; report particle-steps per second and cell-steps per second with the GPU model named, never the hostname.

# A9. Scope: a generic particle–mesh framework

Long term the project is a showcase and stress test for Julia and Reactant compiler technology, with modular physics (extensible, possible EDM integration) and connections to packages such as Molly.jl to be explored; all of it long term. Consequences now, none of which change the phase 1–3 schedule: the engine/physics-module split with the electrostatic PIC module as the proof (`architecture-draft.md` §0.1); the Reactant-compatibility rules and a Reactant CPU smoke test in CI from the first package (§0.4); the particle-workload stress-test suite as a deliverable (§0.2); the name (A6). Everything else in §0 is deferred (C). The main integration goal is SciML; Molly compatibility is a nice-to-have, not a design driver. FastMultipole.jl (CUDA for direct interactions only) is not needed for LWFA.

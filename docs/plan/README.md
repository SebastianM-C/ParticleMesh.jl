# Design record

These documents were written during the planning phase (October 2026) by Claude for Sebastian and are the project's design record. Start with `overview.md`. The owner's aims and decisions are in `../goals/` (A0 to A10); everything here is derived from them and changes through ordinary pull requests, except `factory-and-observability.md`, which holds the factory settings F1 to F4 and is the owner's. Background, read when a work package points there: `landscape-and-requirements.md`, `sciml-reuse.md`, `workflows-primer.md` and the platform facts in section 3 of the factory document. `architecture-review.md` is an external review of the plan (2026-10-31) whose advice to build a runnable spike before fixing the core contracts was taken: A0 states it, `architecture-draft.md` §0.7 was reduced to decisions and proposals, and WP-004 to WP-009 were parked behind the spike WP-010.

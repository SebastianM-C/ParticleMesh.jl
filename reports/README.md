# Reports

Markdown reports with their figures committed next to them, one directory per report. A report is a record, not prose: it starts with a header block naming the work package, the commit, the run ids and the hashes of its inputs, and, once an independent review has run, a Review row (reviewer role, model id, date, findings file, the findings committed next to the report and each answered in it); then setup, results (figures from `scripts/` with their sidecar numbers), verification status, and open issues. A report cites the run manifests it rests on and the work package it belongs to; the overseer's daily digests live in `trace/digests/`. Benchmark numbers and scientific claims get an independent review before a report is cited outside the repository.
